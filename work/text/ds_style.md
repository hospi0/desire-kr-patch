# Desire 번역 교정 기준 (2026-10-07 시작, 하스피 «용어·인물·명사·말투 교정 — 텍스트 어드벤처라 텍스트가 중요»)

입력 `my files/desire번역/*.tsv`(읽기만) → `python tools/ds_fix.py` → `work/trans/desire_ko_NNN.tsv`(빌더 입력).
줄 교정 = `work/text/ds_fixes.tsv`(번호·번역·이유), 바뀐 줄 기록 `work/text/ds_fix_log.tsv`, 남은 문제 `work/text/ds_problems.tsv`.

## 지키는 것
- 원문 제어 토큰({n00} 줄바꿈 · {s00} 멈춤 · {w00}{k00} · {E98x}) 차례 그대로 — 다르면 빌더가 막음.
- 항목 용량: 2장 항목 41 은 원문 +3.2% 까지 → 고칠 때 문장을 늘리지 않는다(되도록 줄인다).
- 띄어쓰기·부호는 빌더가 전각으로 바꿈(, → 、 · … → ‥ · 부호 뒤 공백 삭제). 따옴표는 원문 「」 그대로.
- ⛔미성년(티나 — 섬 생활 때 17세, 현재 시점은 어린아이)을 성적으로 다루는 줄은 번역하지 않음(빈칸 76줄: 08503~08572 · 07961~07962 · 07983~07984 · 05455~05456).

## 말투
- 알: 마코토·티나·카일·실비아·셰릴·엘레나·크리스(친해진 뒤)에게 반말. 레이코·마르티나·카즈미·게이츠·크리스(처음)에게 해요체가 기본이나 원문이 반말로 흐르면 따라감(같은 장면 안에서 원문과 거꾸로 뒤집힌 곳만 고침). 속생각 （）은 반말.
- 카즈미→알: 반말(～わ). 레이코→알: 반말. 마르티나→알: 해요체(～ですわ·かしら 는 해요체로). 엘레나·셰릴→알: 해요체. 티나: 반말·자기를 «티나»라고 부름.
- 카일: 거친 반말. 게이츠: «～네/～군» 하게체.
